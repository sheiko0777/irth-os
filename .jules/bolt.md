## 2025-02-12 - Avoid N+1 queries and full table scans on array loops in APIs
**Learning:** During order creation we iterated items arrays to lookup data using `db.select()` individually per item, creating an N+1 queries problem which drastically increases request latency. We also fetched all existing records (`db.select().from(table)`) just to check their `.length` to generate the sequence numbers, which is very inefficient and hits the database memory limit easily. Finally, we were iterating to insert into the database sequentially.
**Action:** When validating API bodies with items lists, extract keys and batch database lookups using `drizzle-orm` `inArray` to map records into memory (O(1) lookups). Replace `.length` checks of entire collections with aggregate `count()` queries from the database. Always use batch inserting `db.insert(table).values(array)` when inserting rows.
