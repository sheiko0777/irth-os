## 2025-05-31 - Drizzle ORM N+1 Query Traps in Order Creation
**Learning:** In highly nested operations like order creation in `apps/api/src/routes/orders.ts`, it is easy to accidentally introduce N+1 query performance bottlenecks by embedding `db.select()...from(productVariants)` and `db.insert(orderItems)` statements inside a `for` loop over user input (`data.items`). Drizzle does not automatically batch or defer these loops, leading to high latency scaling linearly with item count.
**Action:** Always extract identifiers first (e.g., `data.items.map(i => i.variantId)`) and use `inArray()` combined with in-memory hash maps (`Map`) to perform batched reads and fast lookups. For insertions, construct an array of objects and pass them into `.values(arr)` directly to execute a single bulk insert instead of individual insertions.
