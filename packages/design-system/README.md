# IRTH OS Design System 2.0

The shared visual contract for IRTH OS Web and Mobile.

## Principles

1. **Operational clarity over decoration.** The OS is a working instrument, not a marketing page.
2. **Quiet luxury.** Obsidian, ivory and muted gold create the IRTH world; gold is an accent, never a flood-fill UI color.
3. **Information density without visual noise.** Use hierarchy, grouping and whitespace instead of excessive cards.
4. **Arabic-first and RTL-safe.** Typography and spacing must remain readable in Arabic and Latin scripts.
5. **Touch-first mobile.** Interactive targets are at least 44px and mobile is redesigned as a focused operational flow, not a shrunken desktop.
6. **Motion with purpose.** Fast interaction feedback (120–180ms), restrained transitions (up to 280ms), and full reduced-motion support.
7. **Accessible by default.** Visible focus, semantic states, keyboard support, sufficient contrast, and no information conveyed by color alone.

## Layers

- **Brand layer:** editorial moments, heritage thread, cinematic surfaces.
- **OS layer:** command-center navigation, tables, forms, status, alerts and workflows.
- **Platform layer:** responsive primitives, tokens, accessibility and interaction behavior.

## Components to standardize next

Navigation, command bar, page header, metric strip, data table, filter bar, status badge, timeline, drawer, dialog, form fields, date/range controls, empty state, loading/skeleton, toast, confirmation, mobile bottom navigation, mobile action bar, and contextual quick actions.

## Density modes

- **Comfort:** default for dashboards and review work.
- **Compact:** dense order/inventory tables.
- **Focus:** one-task mobile flows and critical forms.

Do not use brand motion or editorial typography inside high-frequency operational controls unless it improves comprehension.
